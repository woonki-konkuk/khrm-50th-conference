## 보는 방법

`index.html`을 내려받아 브라우저에서 열면 발표 화면이 뜬다.

- 넘기기: ← / → , PageUp / PageDown, 스페이스, 화면 좌우의 ‹ › 버튼
- 전체화면: 슬라이드 더블클릭 또는 F 키 (전체화면에서는 화면 좌우 클릭으로도 넘김)
- 차트 요소에 마우스를 올리면 문항 설명과 값이 보인다

## 내용

「조직과인사관리연구」 심사위원(연구자 25명)과 인사·조직 실무자(36명)를 대상으로 한 설문 결과를 다섯 부분으로 정리했다.

1. 논문 심사 기준 (현재와 향후)
2. 게재불가 이유와 심사 과정
3. 연구 아이디어와 어려움
4. 실무자의 지식 경로
5. 연구와 실무의 간극 (존재 · 불가피성 · 전달 · 생산)
